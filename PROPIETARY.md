# Proprietary Components

## Overview

Fr3squ1nh0ROM is an independent development project.

This repository contains open-source project code, documentation, configuration and other material that can be publicly distributed.

Proprietary Samsung components are intentionally kept outside this repository.

## Components Not Distributed

The public repository does not contain proprietary:

* Samsung firmware
* Vendor blobs
* Modem firmware
* Samsung applications
* Samsung framework components
* Proprietary libraries
* Device-specific binary components
* Other copyrighted Samsung software

## Development

Required proprietary components may be obtained separately and kept in the local development environment where appropriate.

They are not uploaded to the public Fr3squ1nh0ROM repository.

This separation allows the project to publish its own source code, configuration, documentation and development work without redistributing proprietary Samsung software.

## Device-Specific Components

The target device is the Samsung Galaxy A52s 5G (SM-A528B / a52sxq).

Device-specific proprietary components required for hardware functionality are handled separately from the public source tree.

## Transparency

The absence of proprietary components from this repository does not mean that the development build contains no proprietary software.

It means that such components are obtained and handled separately and are not redistributed by this repository.
