# Kernel

## Kernel Source

Fr3squ1nh0ROM uses **Nova-Kernel** as the kernel source/reference for the Samsung Galaxy A52s 5G.

Repository:

https://github.com/m52xq/Nova-Kernel

Nova-Kernel supports the Samsung Galaxy A52s 5G, Galaxy M52 5G and Galaxy A73 5G.

## Target

For Fr3squ1nh0ROM, the target device is:

| Property | Value                    |
| -------- | ------------------------ |
| Device   | Samsung Galaxy A52s 5G   |
| Model    | SM-A528B                 |
| Codename | a52sxq                   |
| SoC      | Qualcomm Snapdragon 778G |
| GPU      | Adreno 642L              |
| Kernel   | Linux 5.4.302            |

## Integration

The kernel is maintained separately from the Fr3squ1nh0ROM repository.

Fr3squ1nh0ROM will use the A52s-compatible portion of Nova-Kernel and adapt the required configuration for the Android 16 / One UI 8.5 environment.

Any project-specific kernel modifications will be documented as development progresses.
